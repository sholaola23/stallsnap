# WhatsApp setup

StallSnap is a catalogue builder: a trader sends a stall photo and a voice note on WhatsApp, and StallSnap sends back a link to a priced catalogue. This page records how the WhatsApp side was set up in Meta's developer dashboard, so it can be repeated.

This repo is public. The page names settings only. Real values (tokens, secrets, phone numbers, the phone number ID and the WhatsApp Business Account ID) live in the host's environment variables and never in git.

## What was done (Mon 26 Oct 2026, after kickoff)

All steps were done in the Meta developer dashboard, in the StallSnap app.

1. **Claimed a test number.** Under WhatsApp > API Setup, "Claim test number" gave the app a free WhatsApp test number. The first attempt failed; a retry worked. Meta created a "Test WhatsApp Account" (a WhatsApp Business Account, or WABA) to hold it.
2. **Gave the server's system user access.** The existing system user `stallsnap-server` was given Full control of the new Test WhatsApp Account in Business settings. The server sends messages with this system user's token, not with a personal or temporary token.
3. **Added a test recipient.** The developer's own phone was added and verified as a test recipient under API Setup. While the app uses a test number, WhatsApp only delivers to verified recipients, and this is the only one so far.

## Settings

Set these as Railway Variables when deploying, plus `PUBLIC_URL` (the server address) and, optionally, `CATALOGUE_STALL_NAME`. `.env.example` lists the same names with no values.

| Variable | What it holds | Where it comes from |
|---|---|---|
| `WHATSAPP_PHONE_NUMBER_ID` | The ID of the WhatsApp test number (not the phone number itself) | WhatsApp > API Setup |
| `WHATSAPP_ACCESS_TOKEN` | The `stallsnap-server` system user's token, with WhatsApp messaging permissions | Business settings > System users > Generate token |
| `APP_SECRET` | The app secret, used to check the `X-Hub-Signature-256` header on each webhook call | App settings > Basic |
| `WHATSAPP_VERIFY_TOKEN` | A random string we choose; Meta sends it back when the webhook is first connected | Generated by us, entered in the webhook settings |
| `ALLOWED_NUMBERS` | The phone numbers StallSnap will answer, in international format, separated by commas | The verified test recipients |
| `MODEL_API_KEY` | The Meta Model API key for Muse Spark, Muse Voice Transcribe, Muse Image and SAM 3.1 | Meta AI developer platform |

## Rules for these values

- Never commit a value, paste one into chat or Discord, or put one in a screenshot. If a token leaks, revoke it in Business settings and generate a new one.
- Only verified test recipients go in `ALLOWED_NUMBERS`. Messages from any other number are dropped before any paid call.
- A client's or someone else's business number is never used for StallSnap.
